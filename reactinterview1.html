1. React Basics

Q1–10
1

What is React?

React is a JavaScript library used to build user interfaces. It lets us create reusable UI components and efficiently update the screen when data changes.

2

What are the main features of React?

Component-based architecture, JSX syntax, one-way data flow, Hooks for state and lifecycle-related logic, and efficient UI updates through reconciliation.

3

What is JSX?

JSX stands for JavaScript XML. It allows us to write HTML-like syntax inside JavaScript. JSX is transformed into JavaScript instructions that React uses to create UI elements.

const element = <h1>Hello React</h1>;
4

What is a component in React?

A component is a reusable piece of UI. It can contain markup, logic, and styling.

function Welcome() {
  return <h1>Welcome!</h1>;
}
5

What is the difference between functional and class components?

Functional components are JavaScript functions and can use Hooks. Class components use ES6 classes and lifecycle methods. Modern React development generally prefers functional components.

6

What are props in React?

Props are inputs passed from a parent component to a child component. They are read-only from the receiving component's perspective.

function Welcome({ name }) {
  return <h1>Hello, {name}</h1>;
}

<Welcome name="Alex" />
7

What is state in React?

State is data managed by a component. When state changes through its setter, React can render the component again to display the updated data.

const [count, setCount] = useState(0);
8

What is the difference between props and state?

Props are received from a parent and are read-only to the child. State is managed by a component and updated using a setter or reducer. Props configure components; state manages changing data.

9

What is the Virtual DOM?

The Virtual DOM is a common term for React's in-memory representation of UI. React compares render results and determines what needs to change in the actual DOM.

10

What is one-way data flow in React?

Data typically flows from parent to child through props. A child can request changes by calling a callback passed by its parent, helping keep data flow predictable.

2. Rendering, Events & Lists

Q11–17
11

What is conditional rendering?

Conditional rendering means displaying different UI based on a condition.

{isLoggedIn ? <Dashboard /> : <Login />}
12

How do you render a list in React?

Use JavaScript's map() method to convert an array into elements.

{users.map(user => (
  <p key={user.id}>{user.name}</p>
))}
13

What is the purpose of the key prop?

A key helps React identify list items across renders so it can determine which items were added, removed, or changed. Use a stable unique ID rather than an array index when possible.

14

How do you handle events in React?

React uses event props such as onClick and onChange. Pass a function reference to handle the event. Avoid onClick={handleClick()} when you intend to call the function only after the click.

<button onClick={handleClick}>Click</button>
15

What is a controlled component?

A controlled form element gets its value from React state and updates that state through an event handler.

const [name, setName] = useState("");

<input
  value={name}
  onChange={e => setName(e.target.value)}
/>
16

What is an uncontrolled component?

An uncontrolled form element keeps its current value in the DOM rather than having React state control it. You can access its value with a ref.

const inputRef = useRef(null);

<input ref={inputRef} />
17

What is the difference between onChange and onClick?

onChange handles changes to form values, such as typing into an input. onClick handles click interactions on buttons, links, and other clickable elements.

3. React Hooks

Q18–27
18

What are React Hooks?

Hooks are functions that let functional components use React features such as state, context, refs, and effects. Examples include useState, useEffect, and useRef.

19

What is useState?

useState adds state to a functional component and returns the current value and a setter function.

const [count, setCount] = useState(0);

<button onClick={() => setCount(c => c + 1)}>
  {count}
</button>
20

What is useEffect?

useEffect synchronizes a component with external systems, such as APIs, subscriptions, or browser event listeners.

useEffect(() => {
  document.title = "Dashboard";
}, []);

// In development Strict Mode, React may run an extra
// setup-and-cleanup cycle.
21

What is the dependency array in useEffect?

  • No array: the Effect runs after every committed render.
  • []: the Effect does not re-run due to reactive dependency changes (though Strict Mode adds a development check).
  • [userId]: the Effect re-runs when userId changes.
  • Rule of thumb: include all reactive values used by the Effect.
22

What is the cleanup function in useEffect?

Cleanup removes or reverses something established by an Effect, such as a subscription, timer, or event listener.

useEffect(() => {
  const id = setInterval(() => {
    console.log("Running");
  }, 1000);

  return () => clearInterval(id);
}, []);
23

What is useRef?

useRef stores a value between renders without triggering a re-render when that value changes. It is also used to access DOM elements.

const inputRef = useRef(null);

<input ref={inputRef} />
<button onClick={() => inputRef.current?.focus()}>
  Focus
</button>
24

What is useMemo?

useMemo caches the result of a calculation between renders while its dependencies remain unchanged. Use it when profiling or the calculation justifies it, not automatically everywhere.

const filteredUsers = useMemo(
  () => users.filter(user => user.active),
  [users]
);
25

What is useCallback?

useCallback caches a function definition between renders while its dependencies remain unchanged. It is useful when stable function identity matters, such as passing callbacks to memoized children.

const handleSave = useCallback(() => {
  saveUser(userId);
}, [userId]);
26

What is useContext?

useContext reads a value from a React context, allowing components to access shared data without passing props through every intermediate component.

const theme = useContext(ThemeContext);
27

What are the Rules of Hooks?

Call Hooks at the top level of a function component or custom Hook, not inside loops, conditions, or nested functions. Call Hooks only from React function components or custom Hooks. These rules help React associate Hook state with the correct component.

4. State Management & Communication

Q28–34
28

What is lifting state up?

Lifting state up means moving shared state into the nearest common parent of the components that need it. The parent passes data and update callbacks to its children.

29

What is prop drilling? How can you avoid it?

Prop drilling means passing props through multiple intermediate components just to reach a deeply nested child. Context, component composition, or a state-management library can help.

30

What is the Context API?

Context lets a parent provide a value to components below it without passing that value through every level. Common use cases include themes, locale settings, and authentication information. Frequently changing context values can cause consumers to re-render.

31

What is Redux?

Redux is a predictable state-management library. It stores shared application state in a centralized store and updates that state through actions and reducers.

32

What is Redux Toolkit?

Redux Toolkit (RTK) is the recommended way to write Redux logic. It simplifies store configuration, reducer creation, immutable updates, and asynchronous workflows. Main APIs include configureStore, createSlice, and createAsyncThunk.

33

What is the difference between Context API and Redux?

Context distributes values through the component tree. Redux provides a structured state-management model with a store, reducers, actions, middleware, and development tools. Use Context for relatively simple shared values; consider Redux for complex shared-state workflows and debugging.

34

How do you update an object or array in React state?

Create a new object or array rather than mutating existing state directly.

setUser(prev => ({
  ...prev,
  name: "Alex"
}));

setItems(prev => [...prev, newItem]);

5. APIs, Routing & Error Handling

Q35–40
35

How do you call an API in React?

You can use fetch or Axios. An Effect is one option for fetching data when a component mounts or its dependencies change. In production, also handle loading, errors, cancellation or stale responses, and HTTP failures.

useEffect(() => {
  async function loadUsers() {
    const response = await fetch("/api/users");
    if (!response.ok) throw new Error("Request failed");
    const data = await response.json();
    setUsers(data);
  }

  loadUsers().catch(setError);
}, []);
36

How do you handle loading and error states?

Maintain separate loading, data, and error states. Display a loader while waiting, the data on success, and an appropriate error message on failure.

if (loading) return <p>Loading...</p>;
if (error) return <p>Something went wrong.</p>;
return <UserList users={users} />;
37

What is React Router?

React Router is a routing library that connects URLs to UI components in a React application. It supports navigation, nested routes, route parameters, and layouts.

<Routes>
  <Route path="/" element={<Home />} />
  <Route path="/users" element={<Users />} />
  <Route path="*" element={<NotFound />} />
</Routes>
38

What is the difference between Link and useNavigate?

Link creates a navigable link that users can click. useNavigate navigates programmatically, for example after a successful login or form submission.

39

What are protected routes?

Protected routes restrict access to pages based on authentication or authorization. The application checks the user's session or permissions and redirects or displays an access-denied page. The backend must enforce actual authorization.

40

What are Error Boundaries?

Error Boundaries catch certain errors thrown while rendering descendant components and show fallback UI. Traditional Error Boundaries use class components. They do not automatically catch errors in event handlers, asynchronous callbacks, or every server-side error.

6. Performance & Advanced React

Q41–47
41

What causes a React component to re-render?

Common causes include changes to its state, new props from its parent, and updates to context it consumes. A parent re-render can also cause child components to render again. A re-render does not necessarily mean React modifies the actual DOM.

42

What is React.memo?

React.memo can skip re-rendering a function component when its props are unchanged according to a shallow comparison. It is most useful when rendering is expensive and props are often unchanged.

const UserCard = React.memo(function UserCard({ name }) {
  return <div>{name}</div>;
});
43

What is reconciliation in React?

Reconciliation is the process React uses to compare the previous and next UI descriptions and determine how to update the rendered result. Component types, tree position, and keys help React decide which elements and state to preserve.

44

What is code splitting and lazy loading?

Code splitting divides application code into smaller bundles. Lazy loading loads a component's code only when needed, which can reduce the initial JavaScript payload.

const Reports = React.lazy(() => import("./Reports"));

// Render <Reports /> inside <Suspense fallback={...}>
45

What is useReducer?

useReducer manages state through a reducer function that receives current state and an action, then returns the next state. It is useful when state transitions are complex or related.

function reducer(state, action) {
  if (action.type === "increment") {
    return { count: state.count + 1 };
  }
  return state;
}

const [state, dispatch] = useReducer(reducer, { count: 0 });
46

What are custom Hooks?

Custom Hooks are JavaScript functions whose names start with use and that can call other Hooks. They let you reuse stateful logic across components. They share logic, not automatically the same state instance.

function useToggle(initialValue = false) {
  const [value, setValue] = useState(initialValue);
  const toggle = () => setValue(v => !v);
  return [value, toggle];
}
47

What is the difference between CSR, SSR and SSG?

  • CSR (Client-Side Rendering): JavaScript in the browser renders the UI.
  • SSR (Server-Side Rendering): the server generates HTML for a request.
  • SSG (Static Site Generation): HTML is generated ahead of time.
  • Frameworks such as Next.js support these approaches.

7. Testing, Security & Real-World Scenarios

Q48–50
48

How do you test React components?

React components can be tested with tools such as Vitest or Jest and React Testing Library. Test what users can see and do, such as rendering text, typing into inputs, clicking buttons, and displaying errors.

expect(
  screen.getByRole("button", { name: "Save" })
).toBeInTheDocument();
49

How do you prevent security issues in React?

Avoid rendering untrusted HTML with dangerouslySetInnerHTML; validate and sanitize untrusted data where appropriate; never expose API secrets in frontend code; enforce authentication and authorization on the backend; and use secure session and token-handling practices. JSX escapes text by default, but not every form of HTML injection is safe.

50

How would you optimize a slow React application?

Profile first to find the bottleneck. Then consider preventing unnecessary re-renders, memoization when beneficial, pagination or virtualization for large lists, code splitting, avoiding redundant API calls, and optimizing images and JavaScript. Explain the problem, chosen solution, and how you measured improvement.

8. Core Concepts Often Asked

Q51–60
51

Is setState synchronous? What are batching and functional updates?

State updates are not applied immediately. React batches multiple updates in the same event (and, since React 18, in timeouts, promises and native handlers too) and re-renders once. The state variable keeps its old value for the rest of that render.

When the next value depends on the previous one, use the functional form so each update sees the latest state.

// count is 0 in this render
setCount(count + 1);
setCount(count + 1); // final result: 1

setCount(c => c + 1);
setCount(c => c + 1); // final result: 2
52

What is a Fragment in React?

A component must return a single parent. A Fragment groups children without adding an extra DOM node, which keeps the HTML clean (useful in tables and flex/grid layouts). Use <>...</>, or <React.Fragment key=...> when you need a key.

return (
  <>
    <h1>Title</h1>
    <p>Text</p>
  </>
);
53

What are synthetic events in React?

A SyntheticEvent is React's cross-browser wrapper around the native event. It has the same interface (preventDefault, stopPropagation, target) and behaves consistently across browsers. React attaches listeners at the root container and delegates events from there. Native event is available as e.nativeEvent.

54

What are class component lifecycle methods and their Hooks equivalents?

Lifecycle has three phases: mounting, updating and unmounting. Interviewers often ask for the mapping:

  • componentDidMount → useEffect(fn, [])
  • componentDidUpdate → useEffect(fn, [deps])
  • componentWillUnmount → cleanup function returned from useEffect
  • shouldComponentUpdate → React.memo
  • getDerivedStateFromError / componentDidCatch → no Hook yet, so Error Boundaries still need a class
55

What is the difference between useEffect and useLayoutEffect?

useEffect runs after the browser has painted, so it does not block the screen. useLayoutEffect runs synchronously after DOM updates but before paint. Use it only when you must read layout (size, position) and update before the user sees anything, such as positioning a tooltip, to avoid flicker. Prefer useEffect by default because useLayoutEffect blocks painting.

56

Why does useEffect run twice in development? What is StrictMode?

<React.StrictMode> is a development-only tool. It renders components twice and, in React 18+, mounts, unmounts and re-mounts every effect once. This helps reveal impure rendering and missing cleanup functions (for example, a subscription or timer that is never cleared). It does not happen in production. The fix is a proper cleanup function, not removing StrictMode.

57

What is a stale closure in React Hooks?

Each render creates its own copy of props and state. A function created in an earlier render (inside setInterval, an event listener or an effect with missing dependencies) keeps seeing the old values.

useEffect(() => {
  const id = setInterval(() => {
    setCount(c => c + 1); // functional update avoids the stale value
  }, 1000);
  return () => clearInterval(id);
}, []);

Fixes: use functional updates, list the correct dependencies (the ESLint exhaustive-deps rule helps), or keep the latest value in a useRef.

58

What are Higher-Order Components (HOC) and render props?

A HOC is a function that takes a component and returns a new component with extra behaviour, for example withAuth(Dashboard). A render prop is a prop whose value is a function that returns JSX, used to share logic. Both patterns share reusable logic, but today custom Hooks are usually simpler and avoid wrapper nesting. HOCs still appear in older codebases and libraries (connect, withRouter).

function withAuth(Component) {
  return function Wrapped(props) {
    const { user } = useAuth();
    return user ? <Component {...props} /> : <Login />;
  };
}
59

What are Portals?

A Portal renders children into a different DOM node outside the parent's DOM hierarchy while keeping them in the same React tree. It is used for modals, tooltips and dropdowns that must escape overflow: hidden or z-index problems. Events still bubble through the React tree, so context and event handling work as normal.

import { createPortal } from "react-dom";

function Modal({ children }) {
  return createPortal(
    <div className="modal">{children}</div>,
    document.body
  );
}
60

What is the children prop? Composition vs inheritance?

children is a special prop containing whatever is placed between a component's opening and closing tags. React recommends composition over inheritance: build complex UI by combining small components and passing content through props and children, rather than extending component classes.

function Card({ title, children }) {
  return (
    <section>
      <h2>{title}</h2>
      {children}
    </section>
  );
}

9. Modern React & Practical Scenarios

Q61–66
61

How do you pass a ref to a child component?

In React 19, function components receive ref as a normal prop. In React 18 and earlier, you wrap the child with forwardRef. Use useImperativeHandle if you want to expose only a limited API (such as focus()) instead of the whole DOM node.

// React 19
function Input({ ref, ...props }) {
  return <input ref={ref} {...props} />;
}

// React 18
const Input = forwardRef((props, ref) => (
  <input ref={ref} {...props} />
));
62

What is Suspense?

Suspense lets you show a fallback UI while part of the tree is not ready yet. It is used with React.lazy for code splitting and with Suspense-enabled data sources (frameworks, TanStack Query's suspense mode, the use Hook). Plain useEffect fetching does not trigger Suspense.

<Suspense fallback={<Spinner />}>
  <Dashboard />
</Suspense>
63

What is concurrent rendering? What are useTransition and useDeferredValue?

Since React 18, React can pause, resume or abandon a render to keep the UI responsive. You can mark updates as non-urgent so typing and clicking stay smooth.

  • useTransition wraps a state update as low priority and gives an isPending flag.
  • useDeferredValue gives a delayed copy of a value so an expensive child (such as a big filtered list) lags behind the input.
const [isPending, startTransition] = useTransition();

function onChange(e) {
  setText(e.target.value);              // urgent
  startTransition(() => setQuery(e.target.value)); // can wait
}
64

What is new in React 18 and React 19?

React 18: createRoot, automatic batching, concurrent features (useTransition, useDeferredValue), and streaming SSR with Suspense.

React 19: Actions for forms and mutations (useActionState, useFormStatus, useOptimistic), the use API, ref as a prop, Server Components support, and built-in document metadata tags such as <title>.

65

What is the difference between server state and client state? Why use React Query?

Client state belongs to the UI (modal open, form input, theme). Server state lives on the backend and can become outdated, so it needs caching, refetching, deduplication and error handling. Libraries like TanStack Query (React Query) or SWR handle this: caching, background refetch, retries, loading and error flags, pagination and cache invalidation after mutations. This avoids storing API data in Redux or hand-writing useEffect fetch logic.

const { data, isLoading, error } = useQuery({
  queryKey: ["users"],
  queryFn: () => fetch("/api/users").then(r => r.json()),
});
66

How do you implement a debounced search input?

Debouncing waits until the user stops typing for a short time before running the expensive work (usually an API call). A reusable custom Hook is the standard answer, and a very common coding round question.

function useDebounce(value, delay = 400) {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id);
  }, [value, delay]);
  return debounced;
}

const debouncedQuery = useDebounce(query);
useEffect(() => { fetchResults(debouncedQuery); }, [debouncedQuery]);
